# The Spot Delivery

Phone-ready ordering app for The Spot Smoke Shop (El Paso / Horizon City).

Customers pick items. Staff from the closest of the 4 shops delivers. Pay at the door. 21+ ID required.

## How to open it today
1. Open `index.html` on a phone or laptop.
2. On iPhone: Safari → Share → Add to Home Screen.
3. Staff board PIN: `2477` (change this before customers use it).

## How an order works
1. Age gate (21+).
2. Customer shops vapes / glass / papers / gear.
3. Checkout: name, phone, address, ZIP.
4. App assigns the closest shop from the ZIP.
5. Customer taps **Text this ticket to the shop** so the store phone gets the order.
6. Driver checks photo ID at the door. Cash or card to driver.

## Rules baked in
- $20 minimum
- $4.99 delivery, free over $40
- Adult signature / ID at door
- Nicotine warning
- Local delivery only

## What this v1 is not

- No live card charge in the app yet (SumUp / Square / Stripe can be added).
